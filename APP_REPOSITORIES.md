## Repository and hosting responsibilities

Native code, backend code, website source, setup and current limitations are described in each guide. Current source snapshots use `codex/source-snapshot-2026-10-23` in existing app repositories. For new repositories source is on `main`. Dedicated overview websites are self-contained in each repository’s `website/`; published copies live in `bayareaapps-site/apps/<project>/`. Blaqly and Kinflare retain their separate Sites hosting source and audience. Critter Care’s interactive website source is backed up under the native repository snapshot’s `website-app/`, with deployment still unconfirmed.

Paws & Whiskers uses the current combined owner repository `Paws-and-Whiskers-Visit`. `Vet-Assistant-Help-Line` remains the historical standalone source and now points to the current app. Earlier BumperCars/Arena-Clash repositories remain historical; `Bumper-Cars` is the current Sky Arena repository. Street Flames belongs to a separate business and is outside this eight-project inventory.
