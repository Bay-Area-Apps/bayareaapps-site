# Kinflare website

Dedicated information website: https://bayareaapps.com/apps/kinflare/

This directory is self-contained static HTML and CSS. Preview with `python3 -m http.server 8080 --directory website` from the repository root, then open http://127.0.0.1:8080/. Its published copy is `apps/kinflare/` in `jmal9767/bayareaapps-site`, served through the existing Bay Area Apps website. After an edit, copy this directory to that route and publish through that repository's existing GitHub Pages setup. This page retains the app's development status and does not activate accounts, app downloads, payments or advertising.
