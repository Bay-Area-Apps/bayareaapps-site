New online visit requests are not being accepted. This page explains the service so you can tell it apart from Help Line, and so an existing visit still makes sense.

What to do right now

The public booking page cannot take a new request, and private visit pages on the website are unavailable. Email info@bayareaapps.com about a visit that already exists. Include the visit reference if you have one. Do not include card numbers, passwords, or a private link you would not want forwarded.

A new question about everyday dog or cat care belongs on Paws & Whiskers Help Line. Sending that request does not book a home visit. Help Line prices are $10 for Focused Guidance, $15 for In-Depth Support, $25 for Phone Support, and no charge for Free Advice. Paid Help Line requests are reviewed before payment.

What a visit is

When booking is open, a request starts with the visit address and a service choice. The menu has been Nail Trim, Medication Care, Sample Collection, and Wellness Check. Those labels are a starting point for review. They are not a promise that every pet or every task is suitable at home.

Wellness Check is not a veterinary examination. Sample Collection is not laboratory testing. Medication Care follows instructions you already have from a veterinarian; it does not create a new treatment plan or a dose. If you are unsure what an option includes, ask before any appointment is confirmed.

A preferred date is a request. Address, the task, and handling needs are reviewed before a time is confirmed.

How a request moves

  1. Request received

    The details are waiting for review. This stage is not a confirmed arrival time.

  2. Confirmed

    The service, time, and amount should match what you expected before any payment.

  3. On the way

    That status means travel has started. It is not a live location and not a minute-by-minute arrival estimate.

  4. After the visit

    Questions about what was done at that appointment stay with the visit. Changes to a veterinarian’s treatment plan go back to that clinic.

More than one pet

Name every pet you want included, with the task and any handling needs, before a visit is confirmed. One pet may need a short task while another needs more time or is not a fit for that visit. Ask for the total and the scope. This page does not set an extra-pet fee, and it does not say additional pets are included.

Mention hiding, handling sensitivities, and any history of biting or scratching. Read the preparation checklist before an appointment that is already scheduled.

Payment and changes

Payment is offered only after a visit is confirmed, and new checkout is not open while the website is paused. If an amount or payment status already looks wrong, email before paying again. A message asking for a different time is not itself a new confirmation. This page does not add a cancellation fee and does not promise a refund.

Keep any private visit link somewhere private. Share the public site address if you are telling someone about the business. If you lose access, use the email above rather than posting the private link.

Need a hand?

Help Line is available today. Visit booking is not. Urgent medical concerns go to a veterinarian or emergency hospital, not to either website.
